# splc Act II Port (Plan 3H) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Replace hand-authored `src/20-act2-block.spl` with a fragment generated from `src_ir/act2.py`, extending the splc compiler where Act II's shape demands it, and restore the wrapper runtime-error contract (design addendum §A4).

**Architecture:** Stage 2 of the staged port in `docs/superpowers/specs/2026-07-05-spl-ir-compiler-design.md` (see Addendum §A1–A4). Three compiler extensions land first, each proven to keep the generated Act I fragment byte-identical: (1) stage pairs are computed from op *targets* only — value references to off-stage characters are legal SPL (`docs/spl/reference.md` line 79: "Character name → that character's current value, even if off stage"); (2) branch questions about an off-pair character render in the third person ("Is Horatio more bold than …?"); (3) entry-pair computation lets goto predecessors adapt at the source to a branch-defined entry stage. Then `src_ir/act2.py` is authored, registered, and gated. Parity is **behavioral** (fixture bytes G1, token stream G2, full suite G3), never textual — the generated fragment will not match the hand-authored text.

**Tech Stack:** Python 3.12 (frozen dataclasses), existing `scripts/splc/` package, `scripts/codegen_html.py` atom machinery, `shakespearelang` parse gate, pytest.

## Behavioral ground truth — Act II decoded

`src/20-act2-block.spl` (183 lines, 13 scenes) is the Slice 1 block-pass
pass-through. State on entry from Act I: **Hecate's stack** holds the input
characters (top = first character), **Horatio** holds the character count.
The act walks the glyphs paragraph-wise and hands Act III a reversed stream:

| Scene | Behavior |
|---|---|
| `ACT_II_START` | LadyM ← Horatio (remaining count); push 1 onto LadyM's stack (stream floor marker) |
| `MASON_READ_PARAGRAPH_GLYPH` | pop Hecate's stack → Hecate (next glyph); LadyM −= 1; if glyph == 10 → CLOSE_PARAGRAPH else KEEP |
| `MASON_KEEP_PARAGRAPH_GLYPH` | push glyph (Hecate's value) onto LadyM's stack; if LadyM == 0 → CLOSE_FINAL else READ |
| `MASON_CLOSE_PARAGRAPH` | push 0 (paragraph seal) onto LadyM's stack; if LadyM == 0 → OPEN_REVERSE else SKIP_BLANK |
| `MASON_SKIP_BLANK_GLYPH` | pop next glyph; LadyM −= 1; if glyph == 10 → AFTER_BLANK else OPEN_PARAGRAPH_WITH_GLYPH |
| `MASON_AFTER_BLANK_GLYPH` | if LadyM == 0 → OPEN_REVERSE else SKIP_BLANK |
| `MASON_OPEN_PARAGRAPH_WITH_GLYPH` | push 1 (floor marker), push held glyph; if LadyM == 0 → CLOSE_FINAL else READ |
| `MASON_CLOSE_FINAL_PARAGRAPH` | push 0 (final seal); → OPEN_REVERSE |
| `MASON_OPEN_REVERSE_STREAM` | *(Hecate exits, Puck enters)* if Horatio > 128 → SET_SLICE_ONE else SET_SHORT |
| `MASON_SET_SLICE_ONE_REVERSE_COUNT` | Puck ← 315 (Slice 1 quirk — port as-is) |
| `MASON_SET_SHORT_REVERSE_COUNT` | Puck ← Horatio |
| `HERALD_REVERSE_TOKEN_STREAM` | pop LadyM's stack → LadyM; push it onto Puck's stack; Puck −= 1; if Puck == 0 → DONE else loop |
| `ACT_II_DONE` | `[Exeunt]` |

Act II anchor: **Lady Macbeth** (on stage in every scene). Mason scenes pair
her with Hecate, herald scenes with Puck. Quirks (315 count, the 1/0
markers) are ported exactly; behavior changes are out of scope (design spec
§Risks).

Three shapes in this act exceed the current compiler; Tasks 1–3 add them:

1. `ACT_II_START` references `val(HORATIO)` while only LadyM and Hecate are
   on stage — `participants()` currently drags expression-referenced
   characters into the pair (`scripts/splc/validate.py:47-70`), and
   `validate()` rejects off-pair references (`validate.py:148-153`).
2. `MASON_OPEN_REVERSE_STREAM` asks about off-stage Horatio: the fragment's
   "Is Horatio more bold than …?" is a **third-person question**;
   `lower.py`'s Branch arm only renders second-person "Are you …?"
   addressed to the tested character.
3. `MASON_OPEN_REVERSE_STREAM` is entered by **branches** from
   CLOSE_PARAGRAPH/AFTER_BLANK (leaving pair LadyM+Hecate) *and* a **goto**
   from CLOSE_FINAL_PARAGRAPH; current `entry_pairs()` records the target's
   own pair for gotos, so mixed predecessors raise a spurious
   "inconsistent stage pairs" error.

### Task 3: Entry pairs — gotos adapt to branch-defined entries

Branch arrivals fix a scene's entry stage (directions render at the target's
scene start, so all branch predecessors must leave the same pair). Goto
arrivals adapt **at the source**: the jump site emits whatever directions
transform its own pair into the target's entry stage. A goto-only scene's
entry is its own pair (today's behavior). This removes the spurious
conflict when a scene has both kinds of predecessors.

**Files:**
- Modify: `scripts/splc/validate.py:100-129` (`entry_pairs`)
- Modify: `scripts/splc/lower.py:193-204` (Goto arm)
- Test: `tests/test_splc_validate.py`, `tests/test_splc_lower.py`

**Interfaces:**
- Consumes: `participants` from Task 1.
- Produces: `entry_pairs(a: Act) -> dict[str, tuple[Char, Char] | None]` (same signature, refined semantics); `lower_act` Goto arm emits directions toward `entry[target]` instead of the target's own pair. Task 4's `MASON_OPEN_REVERSE_STREAM` / `MASON_CLOSE_FINAL_PARAGRAPH` shape relies on it.

```python
def entry_pairs(a: Act) -> dict[str, tuple[Char, Char] | None]:
    by_label = {sc.label: sc for sc in a.scenes}
    entry: dict[str, tuple[Char, Char] | None] = {a.scenes[0].label: None}
    # Pass 1 — branch arrivals fix the entry stage: directions render at
    # the target's scene start, so branch predecessors must agree.
    for sc in a.scenes:
        leaving = participants(sc, a.anchor)
        for op in sc.ops:
            if not isinstance(op, Branch):
                continue
            for target in [op.then] + ([op.else_] if op.else_ is not None else []):
                if target not in by_label:
                    continue
                if target in entry and entry[target] != leaving:
                    raise IrError(
                        f"scene {target}: predecessors leave inconsistent "
                        f"stage pairs ({entry[target]} vs {leaving} from "
                        f"{sc.label})"
                    )
                entry[target] = leaving
    # Pass 2 — goto arrivals adapt at the source, so a goto-only scene is
    # entered with its own pair already staged.
    for sc in a.scenes:
        for op in sc.ops:
            if isinstance(op, Goto) and op.target in by_label:
                entry.setdefault(
                    op.target, participants(by_label[op.target], a.anchor)
                )
    return entry
```
