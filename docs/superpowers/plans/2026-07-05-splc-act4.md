**Deviation from audit (recorded during implementation):** The audit's
recommendation to add the six `DBG_*` entries to `src/40-act4-literary.toml`
is incompatible with `test_scene_titles_have_toml_entries_and_match_source`,
which asserts the globbed production ledger's scene set exactly equals the
production source's. The debug play is not in the production source, so
ledger entries for it would orphan. Instead the debug fragment is rendered
with its titles inlined (kept as `SCENE_TITLES` in `src_ir/debug_act4.py`),
matching the prior hand-authored file's literal-title convention and
requiring no ledger or loader change. Also: the audit's companion list
omitted the five `PUCK`-tested branch-only scenes
(`SCRIBE_TEST_PARAGRAPH_CLOSE`, `SCRIBE_TEST_ANCHOR_{OPEN,TITLE,TEXT,CLOSE}`),
which need `companion=PUCK` because `participants()` counts op targets, not
branch-tested characters.
